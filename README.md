# Natalie Project

Кроссплатформенное веб-приложение для отправки идей, заказов и прайс-листов.

## Стек
- **Backend:** FastAPI, aiomysql
- **База данных:** MariaDB
- **Фронтенд:** React Expo, JavaScript

## Функциональность
- Подача идей и заказов пользователями
- Управление прайс-листом для бизнеса
- Асинхронные REST API endpoints
- Синхронизация данных между клиентом и сервером

## Статус
Функциональный MVP.

## Установка и запуск

### Требования
- Python 3.10+
- Node.js (для фронтенда)

### Бэкенд
```bash
cd backend
pip install -r requirements.txt
# Настройте переменные окружения:
export DB_HOST="localhost"
export DB_USER="your_user"
export DB_PASSWORD="your_password"
export DB_NAME="your_db"

# Запустите сервер
uvicorn main:app --reload
```

### Фронтенд
```bash
cd frontend
npm install
# Запустите приложение
npm start
```

### Схема базы данных
- **users** — пользователи
- **projects** — идеи/проекты
- **orders** — заказы
- **price_lists** — прайс-листы

## Схема архитектуры
```
┌─────────────┐    ┌─────────────┐    ┌─────────────┐
│   Client    │    │   API Gateway│    │   Database  │
│ (React)     │───▶│ (FastAPI)    │───▶│ (MariaDB)   │
└─────────────┘    └─────────────┘    └─────────────┘
```

## Использование
1. **Регистрация / Вход** в систему
2. **Создание проекта** — отправка идеи с описанием и ценой
3. **Заказы** — управление заказами от клиентов
4. **Прайс-листы** — экспорт цен на продукты

## Пример API

### POST /api/projects
```json
{
  "title": "Новый проект",
  "description": "Описание проекта",
  "price": 1000,
  "category": "разработка"
}
```

### GET /api/price_lists
Возвращает список актуальных цен для клиентов.
